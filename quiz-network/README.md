## 启动方式

### 方式 1：双击 HTML（最简）
直接双击 `index.html`，浏览器即可运行。localStorage 正常。
> ⚠️ PWA 特性（离线、添加到主屏幕）需要 `http(s)://` 协议才生效。

直接把整个 `quiz-network/` 目录上传到 Vercel / Netlify / GitHub Pages 即可，无后端依赖。

## 八种题型

| 题型 | 判分 |
|---|---|
| 单选 (single) | 完全匹配 |
| 多选 (multi) | 完全匹配；部分对给 grade=1 |
| 判断 (tf) | T/F 完全匹配 |
| 填空 (fill) | 多空模糊匹配（忽略大小写、空格） |
| 排序 (sort) | DOM 顺序与 sortKey 逐位对比；部分对给 grade=1 |
| 连线 (match) | 所有 left→right 配对正确数；部分对给 grade=1 |
| 简答 (short) | 自评 ★0~3 → grade 0~3 |
| 综合 (comp) | 多子题作答 + 总体自评 |

## SRS 间隔重复算法

实现 SM-2 简化版：

```
grade 0 (重来): interval=1d, ef -= 0.2, lapses++
grade 1 (困难): interval=1d, ef -= 0.2
grade 2 (良好): interval *= ef, ef += 小量
grade 3 (简单): interval *= ef, ef += 0.15
```

- **答对** → 1 天后复习；连续答对 → 3d → 7d → 30d 指数延后
- **答错** → 立即到期（1 天后重做），遗忘次数 +1
- **侧栏胶囊** 实时显示「📅 今日复习 N 题」，点击直接进入 SRS 模式

## 题库导入（JSON）

1. 点击侧栏「📥 导入」 → 「📄 下载模板」得到 `题库导入模板.json`
2. 按模板结构编辑新题，**注意**：
   - 每题必须有 `id`（全局唯一）/ `type` / `cat` / `stem`
   - 题型字段按 type 提供：`answer` / `blanks` / `parts` / `sortItems`+`sortKey` / `matchPairs`
3. 点击「📂 选择文件」上传
4. 冲突题号弹窗选择策略：`merge`(合并) / `overwrite`(覆盖) / `skip`(跳过)

支持的题型 type：`single` / `multi` / `tf` / `fill` / `short` / `comp` / `sort` / `match`

## 常见问题

- **数据存哪了？** `localStorage` key 为 `network-quiz-v2`，可通过"设置 → 导出 JSON 备份"随时备份。
- **换了电脑怎么办？** 导出 JSON → 在新电脑导入。
- **想重头开始？** 设置 → 「🗑 清空所有记录」或侧栏底部「重置全部」。
- **如何安装为 App？** Chrome / Edge 浏览器打开 http(s) 站点 → 地址栏右侧「安装」图标 → 添加到主屏幕。
- **离线能用吗？** 是，首次访问后会缓存所有静态资源，无网可继续使用。
- **简答/综合题怎么评分？** 简答先自评 ★0~3（完全不会~完全掌握），综合多子题作答后总体自评。SRS 间隔按 grade 安排。
- **SRS 是按什么算下次复习时间？** 答对=1天后，下次=3天，7天，30天……；答错=1天后重做。
