# 网关与运营方待确认契约

更新：2026-10-16。本文是待交付契约与验收条件，不代表线上已有这些接口；不据此猜测路径或发送请求。

## 原生验证挑战

现有公开契约仅证实auth/login接收captcha字符串。正常账号登录成功不等于验证挑战已验收。

再次只读核对[线上OpenAPI](https://xllite.sayqz.com/api/v1/openapi.json)：info.version仍为0.1.0，LoginRequest必填username/password，可选captcha/rememberMe；未出现名称含captcha/challenge/verify的挑战模型或路径。auth下还存在prewarm和wechat系列接口，这些不构成CAS验证码图片与关联契约。此检查只读取公开描述，没有发送登录请求、验证码或会话token；版本号相同本身不代表文档内容从未变化。

后端需明确：触发挑战的状态码和错误码、挑战类型、挑战标识、图片或原生可渲染内容的获取方式、有效期、刷新与旧挑战作废规则，以及登录提交时如何关联该次挑战。若涉及第三方验证，需提供其官方支持的应用内集成方式。

验收覆盖：首次挑战显示、刷新替换、错误答案、超时重试、重复点击去重、离开页面取消结果、切换账号不复用挑战。测试账号和验证输入由用户在应用内操作；测试日志只记录状态码与错误分类，不记录密码、token或验证码答案。

## 会话撤销

已有login/session/refresh/logout路径；客户端清理本机会话后立即返回登录页，异步尝试撤销捕获的旧token。远端撤销失败不等于服务器会话已删除，退出也不等于删除账号或学校凭据。

后端需确认：logout的幂等性、撤销范围、刷新后旧token有效性、服务端session和学校凭据是否同步清除。验收应以旧token后续访问失败为证据，并验证旧会话撤销不会撤销另一新会话；涉及token的测试在隔离测试账号中执行，不导出当前用户会话。

## 数据处理与删除

登录页已说明HTTPS网关地址及服务器可能为续登保留凭据；该说明不是正式隐私政策或首次同意流程。

运营方需提供：责任主体与联系渠道、实际处理字段、用途、存储位置、学校凭据存储形式、保存期限、备份保留及到期清除规则、第三方处理方、撤回同意的影响、数据访问及删除申请路径。

若提供删除接口，需明确身份校验、删除范围、是否影响学校原账号、异步任务状态、完成时限、失败恢复和可审计回执。客户端仅在契约确认后接入；本地缓存清除与远端删除在界面中分别说明，不把退出成功显示为远端删除成功。
