# 掌上新理工：上架准备与待办

更新：2026-10-16。定位为用户确认的学校认可官方应用；本文件不代表资质审核通过。仅本地开发及提交，无推送或正式发布。

## 已完成且有证据

- 最低HarmonyOS 6.1.0(API23)，目标/编译API26，完整未签名HAP构建通过；低版本使用原生背景模糊，高版本按设备能力开启ImmersiveMaterial。
- 原生账号密码登录、HTTPS统一网关token、服务端有效期、缓存来源隔离、服务端退出撤销；临近过期时在业务请求前续期，不因业务错误重放支付。
- 公开接口与13项业务名称/示例已核对；未使用用户凭据，未执行充值或支付。真实个人数据成功率尚无结论。
- 原创新理之山位图：山脊与书页、靛蓝背景；1024方形不透明PNG为527776字节，另有216版本。应用级、启动/Ability与商店1024资源SHA256相同。生成原稿另存，不将其称为矢量源稿或用户已定稿。

## 发布前仍需完成

- API23及API26设备安装、冷启动、前后台、玻璃回退、深浅色、文字缩放、触控与减少动效验收。当前hdc无连接目标。
- 用户在应用内手动登录，再逐项核实个人信息、课表、成绩、考试、培养方案、余额与流水；不在聊天中提交密码，不采集token日志。
- 验证码图片与二次验证：目前公开契约仅有captcha提交字段，没有挑战图片/会话关联接口；需网关补齐明确契约后验证完整原生交互，单个输入框不算完成。
- 审核网关服务实际数据处理：公开描述表明密码登录session可能由服务器保留用于学校token续登；本机不保存密码并不等于服务器不处理或保留密码。学校需确认服务运营方、数据位置、保存期、删除路径及责任主体。
- 正式隐私政策、用户协议、首次明确同意、撤回同意、注销/删除入口、服务联系信息与稳定HTTPS公开链接。当前不填造学校联系人、备案号或承诺。
- 学校主体、应用名称/标识使用确认材料、软件著作权及备案等按AGC实际所需补齐；官方身份不由代码或图标推定。
- 正式签名证书/描述文件、release非调试包、版本号、审核测试账号和操作说明；现有产物为开发未签名HAP，不作为商店提交包。
- 3–10张真实设备界面截图，竖屏1080x1920或横屏1920x1080，避免密码、付款码与个人信息泄露；图标与商店保持一致。尚未制作截图，不以设计稿冒充设备截图。
- 图标小尺寸/系统遮罩设备验收与矢量母版制作；当前交付是可复导出的栅格资源，不是矢量原稿。
