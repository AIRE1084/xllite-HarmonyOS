## 找回密码链路

这一步此前只有代码与回归，没有真机确认。本轮实测：

1. 冷启动进入登录页，布局导出得到四个文本节点：`掌上新理工`、`登录`、`忘记密码`、`登录与数据说明`。
2. 点击「忘记密码」（坐标为按钮 bounds 中心 `658,1927`），界面切换到找回密码页。
3. 切换后的文本节点为：`找回密码`、`密码由学校统一身份认证平台管理。请联系学校信息服务部门重置密码，完成后在这里重新登录。`、`重新登录`。
4. 点击「重新登录」（`658,1651`），完整回到登录页，四个节点全部复现。

**结论**：应用内不存在伪造的重置流程，也没有任何表单或"发送验证码"按钮。这与 `docs/PLATFORM-CONTRACTS.md` 第 1 节一致，与该文档对应的两条回归用例一致。
